# FocusGuard - Pengelola Waktu Layar

FocusGuard adalah aplikasi web sederhana yang dirancang untuk membantu Anda memantau waktu layar (*screen time*), mencatat durasi penggunaan aplikasi harian, serta menyediakan fitur *Mode Fokus* (Pomodoro) agar lebih produktif dan terhindar dari distraksi gawai.

## Fitur Utama
1. **Dashboard Kuota Harian:** Melacak total durasi penggunaan aplikasi dibandingkan dengan batas waktu harian yang Anda tentukan sendiri. Dilengkapi indikator progress bar visual.
2. **Mode Fokus (Pomodoro Timer):** Timer hitung mundur 25 menit untuk membantu Anda fokus belajar atau bekerja tanpa memegang HP.
3. **Pencatat Waktu Aplikasi:** Menyimpan riwayat penggunaan aplikasi (seperti media sosial atau game) menggunakan penyimpanan lokal browser (`localStorage`) agar data tidak hilang saat halaman disegarkan.
4. **Dark / Light Mode:** Mendukung mode tampilan gelap dan terang agar nyaman digunakan di berbagai kondisi pencahayaan.

## Cara Menjalankan Secara Online (GitHub Pages)
1. Unggah (*upload*) seluruh file (`index.html`, `style.css`, `app.js`, `README.md`) ke repository GitHub Anda.
2. Masuk ke menu **Settings** pada repository Anda.
3. Pilih menu **Pages** di bagian sisi kiri.
4. Pada bagian **Branch**, ubah dari `None` menjadi `main` (atau `master`), lalu klik **Save**.
5. Tunggu 1-2 menit, dan GitHub akan menampilkan tautan (*link*) web Anda di halaman tersebut. Aplikasi siap diakses dan digunakan langsung dari HP Anda!
